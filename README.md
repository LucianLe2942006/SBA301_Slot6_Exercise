# React Hook Product Manager

## Course
SBA301 - Slot 6 - React Hook

## Features
- Frontend CRUD: add, edit, delete
- Search and category filter
- Product statistics
- Dark/light theme
- localStorage persistence
- Auto-focus search input
- document.title effect

## Hooks demonstrated
- useState
- useEffect
- useContext
- useRef
- Custom Hooks: useLocalStorage, useTheme

## Run
npm install
npm run dev

## Build
npm run build
npm run preview
